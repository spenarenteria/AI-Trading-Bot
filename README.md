## AI Trading Bot

An AI trading bot built with Python that uses FinBERT to analyze financial news and make trading decisions.

## How it works

The bot gets market news from Alpaca, uses FinBERT to detect the sentiment, and makes buy or sell decisions based on the results. It also uses Lumibot to backtest the strategy with historical market data.

## Used technologies

Python, FinBERT, PyTorch, Lumibot, Alpaca API, and Yahoo Finance.
